# class-aware-dp-gbc

Code and experimental results for **"Class-Aware Granular-Ball Partitions for Pure ε-Differentially Private Release of Labeled Numerical Data."**

## Running the Code

The experiments are implemented in Jupyter notebooks and can be run using **Google Colab**.

1. Open the required `.ipynb` notebook.
2. Upload it to [Google Colab](https://colab.research.google.com/) or open it directly from GitHub.
3. Set up the required datasets and dependencies as indicated in the notebook.
4. Run the notebook cells in order.

## Reproducibility

The notebooks and result files are provided to support transparency and reproducibility of the experiments.
